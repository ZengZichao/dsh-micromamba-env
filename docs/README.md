## 什么时候会卡住

- 侧边栏找不到 **Micromamba**：先看 [故障排除：侧边栏没有 Micromamba](./troubleshooting.md#侧边栏没有-micromamba)。
- 面板里出现 **读取失败：…**：按提示文字去 [故障排除](./troubleshooting.md) 对应小节。
- 说不上来某个标签的含义：读 [三个标签与只读边界](./concepts.md)，再回到刚才那篇继续。

## 这套文档的约定

- 加粗文字是界面上的原文标签，照抄即可，包括中文界面里的 **刷新**、**筛选软件包**、**未选择**；正文里的重点用普通文字，不再加粗。
- 每一步只做一个动作；需要连续点两下的地方会拆成两步。
- 每篇末尾单独一行的 **结果** 写的是成功时你看到的画面，用来判断到底成没成。
- 标着"截图位"的地方是留给维护者补图的，旁边写了这张图该拍什么。
