# 查看某个环境里装了哪些软件包

展开一个环境，就能看到它全部已安装包的名称、版本和 channel，并能按包名或版本筛。

1. 点击侧边栏的 **Micromamba**。
2. 点击目标环境行。
   > 提示：整行都是可点区域，点环境名或路径效果一样。用键盘时先 Tab 到该行，再按 Enter 或空格。
3. 在展开区等待 **正在读取…** 变成列表。环境很大时这一步要几秒，因为插件在跑一次 `micromamba list`。
4. 在 **筛选软件包** 输入框里输入包名或版本片段。
   > 提示：筛选不区分大小写，输入 `PY` 同样能筛到 `python`；清空输入框即恢复全部。
5. 读三列：包名（等宽字体）、版本、channel。
6. 把鼠标停在任意一行上，读提示里的 build 字符串。
   > 提示：build 不在列里显示，只在这一行的悬停提示中，形如 `numpy 1.26.4 py311h...`。
7. 再点一次该环境行收起。

**结果：** 展开区列出形如 `numpy 1.26.4 conda-forge` 的行；输入 `py` 后只剩包名或版本含 `py` 的包，**筛选软件包** 右侧的计数从 `480/480` 变成 `37/480`。

> 截图位：某个环境展开后的包列表，包含 **筛选软件包** 输入框、它右侧的计数和两三行包。alt：环境展开区域，筛选框内输入 py，列表只剩名字含 py 的包，筛选框右侧显示 37/480。

## 计数与空状态怎么读

- `37/480`：左侧是当前可见条数，右侧是本次取到的总条数。
- **没有匹配项。**：筛选框里有内容但没有包命中。筛选只比对包名和版本，不比对 channel 和 build。
- **没有软件包。**：这个环境确实是空的，或者 `micromamba list` 返回了空数组。
- 红字 **读取失败：…**：这个环境的包列表读不出来，先按 [故障排除](./troubleshooting.md#某个环境的包数是破折号或读取失败) 处理。
