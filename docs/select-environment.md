# 为当前工作区选择 micromamba 环境

让每个工作区各记一个环境：切回这个项目时，选择器自动恢复成上次那个，不用重新选。

需要：工作区已在应用里打开（输入框可见）；目标环境已出现在 **Micromamba** 面板里。

1. 打开目标会话，把光标放进输入框。
2. 点输入框左侧的环境选择器。
   > 提示：选择器外形是一枚六边形图标加当前环境名；没选过时显示 **未选择**。它只有一个按钮，不是输入框。
3. 在弹出菜单里点目标环境。
   > 提示：菜单每一项第一行是环境名，第二行灰字是它的绝对路径。同名环境靠路径区分。
   > 截图位：选择器展开后的菜单，含 **未选择** 和两三个环境（名称 + 路径）。alt：环境选择器菜单，第一项为未选择，下面每项显示环境名与绝对路径，当前项左侧有对勾。
4. 看菜单里的变化：选中项左侧出现对勾，环境名变粗。
5. 切到另一个工作区，重复第 2–3 步。
   > 提示：选择是按工作区保存的，不是全局。换工作区就该换环境，这正是它的用途。

**结果：** 选择器显示所选环境名；**Micromamba** 面板顶部的 **环境** 一栏同步显示同一个名称。

## 选择存在哪里

写在 `<工作区>/.context/micromamba-environment.json`，内容形如：

```json
{
  "workspace": "/Users/you/project",
  "environment": {
    "name": "science",
    "path": "/Users/you/micromamba/envs/science",
    "source": "micromamba"
  },
  "updatedAt": "2026-11-14T10:20:31.000Z"
}
```

> 提示：不想让同事或 CI 继承你的选择，把 `.context/` 加进项目 `.gitignore`。

## 清除选择

在菜单里点 **未选择**。文件里的 `environment` 变成 `null`；此后 Bash 里的 Python 命令不再被拦去 `micromamba_run`。
